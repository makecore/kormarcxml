# Changelog

## 0.1.0 — 2026-09-16 — Initial development release

- Added ordered KORMARC record models and copy-returning field edit helpers.
- Added bounded ISO 2709 parsing/writing with regenerated byte directory values,
  explicit legacy codecs, strict encoding defaults, and constrained recovery.
- Added secure streaming XML transport and an independently authored XSD using
  the generic MARCXML vocabulary.
- Added source-linked partial bibliographic rules, separate tagging/content
  validation, institutional profile merging, and structured issues.
- Added HTML/tagged presentations, validation-report HTML, JSON adapter,
  conservative lossy DC/MODS crosswalks, and analytics CSV.
- Added CLI conversion, validation, inspection, transformation, and batch commands.
- Added synthetic round-trip demonstrations, adversarial tests, independent
  structural checks, a streaming benchmark, and CI configuration.
- Added bilingual READMEs, architecture decisions, provenance, limitations,
  API guidance, LC component parity matrix, and a staged roadmap.

This version is unofficial and implements partial semantic coverage. Release date
identifies the development snapshot, not evidence of GitHub/PyPI publication.
