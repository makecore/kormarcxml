# 부록 A·D 및 880 연결 규칙 검수

2026-09-19 검수. [부록 A](https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/appendix_a.html), [부록 D](https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/appendix_d.html), [880](https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/841_89X_880.html)의 원문 캐시를 대조했다. 원문 해시는 `src/kormarcxml/resources/rules/linkage.json`에 기록한다. 설명문 전체를 재배포하지 않는다.

검사는 수준 3에서 실행하며 원문·문자순서·필드순서를 변경하지 않는다. XML은 기존 `subfield code="6"` 및 `subfield code="8"` 문자열 표현을 유지한다. 연결 관계를 XML 중첩이나 새 식별자로 바꾸지 않는다.

| 원문에서 확인한 사항 | 구현 | 경계 |
|---|---|---|
| `$6` 표시기호 3자리·발생번호 2자리 | 형식 및 연결 대상 검사 | 발생번호는 필드 순서가 아님 |
| `$6`은 첫 식별기호 | 데이터 앞에 위치하는지 검사 | 880의 선두 반복은 KX-012 경고 |
| 일반 필드 ↔ 880 상호 연결 | 표시기호·발생번호 대응 검사 | 일반 필드 하나에 여러 880 허용 |
| 서로 다른 연결 세트는 다른 발생번호 | 일반 필드 중복 번호 검사 | 같은 880 세트의 여러 문자 표현 허용 |
| 880 발생번호 `00` | 상대 필드 요구 제외 | 일반 필드에는 이 예외를 적용하지 않음 |
| 880의 관련 필드 지시기호 값 | 연결 상대와 값 비교 | 전체 식별기호 의미 상속은 아직 미구현 |
| 문자부호·방향 `/r` | 기존 부호 및 문법 검사 | ISO 15924는 형식만 확인하고 미확인 경고, 문자 내용으로 부호 추정 안 함 |
| `$8` 연결번호·선택 일련번호 | ASCII 정수 형식 검사 | 큰 정수도 문자열로 처리, 자동 재번호 없음 |
| 연결유형 `a/c/p/r/u/x` | 허용값 검사, `x`이면 일련번호 요구 | 기본값 `u` 자동 삽입 없음 |
| 같은 연결번호의 일련번호 사용 일관성 | 하나라도 사용하면 모든 해당 `$8`에 요구 | 연속 번호·유일 번호·물리적 정렬을 추가 강제하지 않음 |
| 85X–87X 유형 생략 예외·852 별도 의미 | 프로파일에 `$8`이 정의된 85X–87X 예외, 852 제외 | 소장 규격 전체 지원을 뜻하지 않음 |

숫자 연결번호의 앞자리 0은 그룹 비교 시 같은 정수로 취급하되 입력 문자열은 보존한다. 미등록·로컬 필드의 `$6/$8` 의미를 자동 추정하지 않는다. 880이 프로파일에서 연결 규정을 확인하지 못한 필드를 참조하면 `peer-unverified` 경고를 낸다. 관계 조회는 연결쌍별로 색인하여 잘못된 대규모 그룹을 반복 전수검색하지 않는다.

## 잠정 방침과 전문가 결정

- **KX-012:** 880 요약은 `$6` 반복불가이나 부록 A의 ISO 15924 예시는 반복한다. 880 반복은 보존·경고, 일반 필드의 기존 반복불가 검사는 유지한다. 서로 다른 연결 대상이 반복되면 추가 검토 경고를 낸다. 최종 반복 허용 조건과 선두 위치 해석 결정 필요.
- **KX-013:** 부록 A·880에는 CJK 부호가 `▾1`, 부록 D에는 `$1`이다. `$1`을 지원하고 `▾1`은 경고와 함께 보존한다. 실제 ISO 식별기호 구분 바이트로 교체하지 않는다. 공식 표기의 교환 바이트 의미 확인 필요.
- **KX-014:** `$8`의 형식에는 ASCII 역슬래시, 예시에는 `∖`(U+2216)가 있다. 둘 다 분석하지만 후자는 경고하며 자동 변환하지 않는다. 교환용 구분 문자 확정 필요.

세 항목 모두 최종 결정이 필요하며 `research/expert-decisions.json`에 잠정 방침·선택 이유·영향 범위·최종 결정 상태를 기록했다. 잠정 해석은 공식 표준 정정이 아니다.

## 검증과 잔여 범위

`tests/test_linkage.py`는 상호 연결, 일대다, `00`, 지시기호, 반복 모순, 순서, 문자부호, 유형, 그룹 일련번호, 소장 예외, 큰 숫자, 사용자 프로파일, 원문 보존을 확인한다. 전체 테스트 461개 통과. 공식 부록 D 보조 실험에서도 6개 그룹·73개 필드의 전송 왕복이 유지되었다. 과거 440의 미확인 연결 경고가 추가되었으며 운영 ISO 표본 검증과는 구별한다.

남은 작업: 880의 관련 필드 전체 의미 상속, ISO 15924 부호표 대조, 링크 유형별 본문 적용 조건(특히 복제자료 예외), 소장용 상세 규격, 적용수준별 필수성, 그 밖의 본문 조건. 이 문서는 부록 전체 또는 표준 전체 검수 완료 선언이 아니다.
