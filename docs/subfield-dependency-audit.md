검사는 **같은 필드의 같은 발생** 안에서 수행합니다. 다른 031이나 034의 식별기호를 합쳐 조건을 충족시키지 않습니다. 수준 3에서만 적용하고 레코드는 변경하지 않습니다. 구문이 읽히는 비정상 입력도 파서 단계에서 버리지 않습니다.

9개 검사 템플릿 중 1개는 잠정 검토 경고입니다. 정상·오류·생략·역방향 오추론 방지·반복 필드 간 분리·원문 불변성은 `tests/test_dependencies.py`에서 시험합니다. 전체 017/031/034의 모든 내용 규정 검수 완료를 뜻하지 않습니다.

## 규칙 확장 방식

`fields[tag].dependencies`의 각 항목은 `id`, `source`, `message`를 가집니다. `when.any_subfields`, `when.absent_subfields`, `when.min_count`, `when.subfield_values`로 적용 조건을 제한합니다. `requires`는 같은 필드의 식별기호 존재, `indicator`는 지시기호 값, `precedes`는 지정된 두 기호의 순서를 검사합니다. 순서 검사는 두 기호가 모두 있을 때만 적용합니다. `review_only`는 적용 조건을 만족하면 경고 등 지정 심각도로 검토 요청을 냅니다. 기관 프로파일에서 목록을 덮어쓸 때는 기존 규칙이 대체된다는 점을 확인해야 합니다.
