# 전문가 결정 필요 사항

검토일: 2026-09-18. 아래 항목은 **미결정**입니다. 공식 규격의 정정이나 해석을 프로젝트가 대신 확정하지 않습니다. XML 원문 보존과 의미 적합성 판정은 별개입니다.

각 항목의 결정 기록에는 `결론 / 결정자·소속 / 결정일 / 근거 문서·판본 / 적용 대상 / 관련 테스트`를 남깁니다. 기관별 운영 정책과 규격 자체의 해석도 구분합니다.

## KX-001 — 개별자료 형태 자리의 채움문자

- [ ] 공식 해석 확인 및 적용 범위 결정
- 유형: 규범 해석. 담당 역할: KORMARC 규격 전문가.
- 근거: [008 총칙](https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/00X_008.html), [도서 상세](https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/00X_008_2.html). 자료유형별 8개 상세 페이지에도 같은 문제를 확인했습니다.
- 관찰: 총칙은 해당 자리의 채움문자를 금지하지만 자료유형별 설명은 허용합니다.
- 질문: 총칙과 상세 중 어떤 규정을 적용해야 하며 006 대응 자리에도 같은 해석을 적용합니까?
- 선택지: 총칙 우선 / 상세 우선 / 판본·프로파일별 구분. 어느 것도 승인된 상태가 아닙니다.
- 영향: 도서·전자자료·음악·계속자료·고서·복합자료 008/23, 지도·시청각자료 008/29 및 006 대응 자리.
- 임시 처리: 원문을 보존하고 해당 자리의 허용값 판정을 보류합니다. 나머지 확정된 자리의 검증은 계속합니다.
- 결정 기록: 미작성.

- 질문·선택지: 반복 가능 / 반복 불가 / 특정 조건에서만 허용 중 어느 규정입니까?
- 영향: 240$2 반복 제약만 미확정이며 XML 매핑에는 영향이 없습니다.
- 임시 처리: 식별기호를 보존하고 반복 제약은 적용하지 않습니다.
- 결정 기록: 미작성.

- 임시 처리: 2026-09-17 수집 스냅샷의 명시적 부호를 대조합니다. 미등재 값은 경고만 내며, 등재 값도 현행 유효성을 인증하지 않습니다. 자동 교체하지 않습니다.
- 결정 기록: 미작성.

## KX-004 — 언어부호표의 Kashmiri 항목

- [ ] 공식 정정 또는 적용 판본 확인
- 유형: 원문 표기 확인. 담당 역할: 부호표 관리 담당자.
- 근거: [언어부호표](https://librarian.nl.go.kr/kormarc/KSX6006-0/sub/annex_3.html).
- 관찰: 수집한 HTML에서 Kashmiri의 부호가 3자리가 아닌 `c`입니다.
- 질문: 공식적으로 적용할 3자리 부호와 정정 근거는 무엇입니까?
- 임시 처리: `c`는 추출 미해결 값으로 기록하고 허용 부호 목록에 넣지 않습니다. 다른 표에서 추정한 값으로 원문을 바꾸지 않습니다.
- 결정 기록: 미작성.

## 전문가 결정과 구분하는 후속 작업

- 031$s, 377$l, 610$n의 불완전한 괄호 표기는 추출기와 원문을 수동 대조할 기술 검수 항목입니다. 단순 표기 문제까지 정책 결정으로 넘기지 않습니다.
- 소장용 규격으로 위임된 17개 필드는 별도 규격 조사 대상입니다. 현재 통합서지 검수 완료로 계산하지 않습니다.
- 모든 필드의 본문 조건·예외·상호 관계 검수는 여전히 진행 대상입니다. 위 5개 항목을 결정해도 전체 의미 검증이 자동으로 완료되지는 않습니다.
