# 가변길이필드 세부 검수 기록

검수일: 2026-09-18. 대상은 보존된 공식 HTML 원문이며, 출처별 해시는
`research/source-inventory.json` 및 보정된 식별기호의 `review.source_sha256`에 남겼다.
아래는 이번에 검토한 범위다. 전체 232개 개별 필드 본문이나 17개 소장규격 위임 필드의
의미 검증이 완료되었다는 뜻이 아니다. XML 전송 경로가 있다는 사실과 내용 검증 완료는 다르다.

앞의 세 건은 새로운 목록 정책 선택이 아니다. 원문에 명시된 반복 단어를 판독한 것이다.
`build_source_catalog.py`는 **해당 태그·식별기호와 검토한 원문 문자열이 모두 일치할 때만**
이 표기 오류를 처리한다. 내용이 변경되면 자동으로 추정하지 않고 미검토로 남긴다.
각 보정의 근거와 원문 해시를 catalog와 validator registry 양쪽에 기록한다.
전체 필드의 검토 상태는 계속 본문 미완료로 유지한다.

## 시험 근거

`tests/test_summary_review.py`:

- 보정된 세 식별기호의 반복 허용 및 입력 불변성.
- catalog → validator registry의 검토 근거 보존.
- 원문 변경 시 보정을 적용하지 않는 방어 동작.
- 240$2의 미결정 유지.
- 020의 입수조건만 있는 경우와 취소번호만 있는 경우 허용.

다음 검수는 제어 식별기호와 다문자 연결, 필드 간 조건, 적용수준을 포함해야 한다.
본문을 읽었다는 사실만으로 조건의 구현·테스트까지 완료 표시하지 않는다.

## 본문 식별기호와 요약 대조 추가

본문의 식별기호 제목을 요약 목록과 대조하여 502$o, 583$z, 890$b 누락을 확인했습니다. 502 요약은 숫자 $0, 583 요약은 $c 중복 및 $x 명칭 불일치, 890 요약은 $a를 사용합니다. KX-008~010에 따라 양쪽 기호를 보존하고 사용 시 경고합니다. 자동 이름 변경이나 의미 교체는 하지 않습니다.

341의 ▾0·▾1 표기는 본문의 **지시기호 설명**에 위치합니다. 이를 새로운 식별기호로 추가하지 않았습니다. 자동 추출 후보를 의미 판독 없이 적용하지 않는 사례입니다.
